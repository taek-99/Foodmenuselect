2. 내 페이지는 렌더 시점에 이미 번들에 포함되어 있어 비동기 로딩이 발생하지 않음
- 학습용으로 구현하기 위해 lazy import 적용
- 비동기식으로 가져오게 하여 suspense 구현

- import 방식과 lazy 방식 차이
    - import 
        - 처음 페이지 로딩 시 A, B, C 관련 JS를 다 같이 다운로드
        - 장점
            - 한 번 로드되면 이후엔 빠름
            - 코드가 단순하고 디버깅 쉽다
        - 단점
            - “처음 화면에서 안 쓰는 기능”까지 몽땅 가져오면 초기 로딩이 불필요하게 느려질 수 있음
            - 특히 대시보드, 에디터, 모달 많고 페이지 복잡할수록 더 심해짐

    - lazy
        - A가 실제로 렌더 트리에 등장할 때 그때 import 실행
        - 네트워크 레벨에서 보면: 초기 로딩: A 관련 JS는 안 받음
        - 필요해지는 순간: 그 때 A용 JS 청크를 추가로 받음
        - 장점
            - 초기 화면 로딩 속도 최적화에 좋음 (특히 “처음 화면에서 안 보이는 UI들”에 효과적)
            - 자주 안 쓰는 기능(설정 페이지, 대형 그래프, 복잡한 모달 등)을 뒤로 미룰 수 있음
        - 단점
            - A가 처음 필요해지는 그 순간에는 로딩 딜레이가 생김 (Suspense fallback으로 가려줌)
            - 너무 잘게 쪼개서 lazy 걸면, 여기저기서 JS 쪼가리 계속 받아오느라 오히려 버벅일 수 있음
